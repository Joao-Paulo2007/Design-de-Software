# Checklist de qualidade — referência ISO/IEC 25010

Avalie o NexusLog nas dimensões pertinentes ao projeto:

- Adequação funcional: os fluxos cobrem os requisitos?
- Eficiência de desempenho: há operações desnecessárias?
- Compatibilidade: integrações estão isoladas?
- Usabilidade: os fluxos são claros mesmo sem frontend?
- Confiabilidade: falhas externas são identificáveis?
- Segurança: dados sensíveis aparecem em logs?
- Manutenibilidade: é fácil incluir nova transportadora ou modalidade?
- Portabilidade: existem dependências rígidas de ambiente?

Registre evidências, não apenas notas.
