# Relatório de Achados Técnicos — Aula 03

Analise `LegacyShippingService`.

## Evidências sugeridas
1. Acoplamento excessivo: cálculo, integração, notificação e log na mesma classe.
2. Baixa coesão: responsabilidades diferentes agrupadas.
3. Crescimento de `if/else` para cada modalidade e transportadora.
4. Dificuldade de testes isolados.
5. Risco de alteração em cascata.
