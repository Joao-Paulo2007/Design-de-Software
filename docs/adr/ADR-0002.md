# ADR-0002: Aplicativo para Reduzir Filas de Uma Cantina de Campus

## Status
[Proposto]

## [Contexto](docs/adr/mapa-contexto-0002.md)
Um campus está com problema para lidar com longas filas no horário de almoço, com muitas pessoas apenas desistindo de esperar na fila. A coordenação quer testar um app simples, onde o aluno reservará o que ele deseja comer, pagando adiantado pelo app, e apenas indo em uma fila para receber a comida já preparada.

## Decisão

Para criar o software, decidimos fazer-lo como um aplicativo de celular, por conta da facilidade de todos acessarem, com o aplicativo necessitando de login para ser utilizado, com o número da matrícula como usuário, e o cpf como senha.

A ideia do sistema é que ele vai diminuir a fila agindo que nem o Burguer King, ou seja, o usuário irá entrar no aplicativo, selecionar o que ele quer comprar, já deixando o pedido ser preparado, e então aguardar o horário de almoço para a retirada. Com isso, o aluno receberá um código, que deverá mostrar para a retirada da comida. Após realizar o pagamento presencial na cantina o aluno poderá retirar o seu pedido.

Agora para aqueles que pagarem a comida e não forem retirar ela, a cantina reterá o valor que já foi pago, a não ser que já tivesse tido um aviso prévio de cancelamento, ou a busca do local para informar um motivo válido para o acontecido.

Para retirar o pedido, o aluno deverá chegar no local, e exibir o código de retirada do produto. Entretanto, para que o usuário consiga sabe quando e se o pedido dele está pronto, o próprio aplicativo avisará dessa conclusão e que ele está pronto para retirar

Passando para os funcionários agora, o responsável pelo atendimento irá receber os pedidos pelo aplicativo e redireciona-los para os cozinheiros. Além disso ele também irá visualizar o código e entregar o pedido para o aluno. Já os cozinheiros, além de receber e preparar os pedidos, eles também irão marcar eles como concluído, fazendo essa notificação aparecer para o aluno.

## Alternativas Consideradas

1- Pagamento realizado pelo aplicativo
- Função de agendar o horário de retirada do pedido

Desconsiderado por conta da confiabilidade de pagamento presencial na cantina

2- Agendar o horário de retirada
- Mais fácil para o aluno
- Evita filas em um horário específico

Foi desconsiderada por conta de aumentar o trabalho constante dos cozinheiros, fazendo o trabalho deles mais exaustivo.

#### Vantagens

Como vantagem, nós temos uma redução do tamanho de fila, já que o aluno agora só se direciona para a cantina para pegar o seu pedido
