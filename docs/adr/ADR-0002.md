# ADR-0002: Aplicativo para Reduzir Filas de Uma Cantina de Campus

## Status
[Proposto]

## [Contexto](mapa-contexto-0002.md)
A coordenação quer testar um aplicativo simples, onde o aluno poderá realizar seu pedido antecipadamente e apenas se dirigir à cantina para efetuar o pagamento e retirar a comida já preparada.

## Decisão

Para criar o software, decidimos fazer-lo como um aplicativo de celular, por conta da facilidade de todos acessarem, com o aplicativo necessitando de login para ser utilizado, com o número da matrícula como usuário, e o cpf como senha.

A ideia do sistema é reduzir as filas permitindo que o usuário faça seu pedido antecipadamente pelo aplicativo. O aluno acessará o sistema, selecionará os itens desejados e enviará o pedido para a cantina, permitindo que ele seja preparado antes do horário de almoço. Ao concluir o pedido, o aplicativo gerará um código de retirada. Quando chegar à cantina, o aluno realizará o pagamento presencial, apresentará o código e receberá seu pedido.

Caso o aluno realize o pedido e não compareça para buscá-lo, o pedido será considerado abandonado após um período definido pela cantina. Como o pagamento é realizado apenas na retirada, não haverá cobrança antecipada, ficando a critério da cantina definir o procedimento para esses casos.

Para retirar o pedido, o aluno deverá chegar à cantina, realizar o pagamento e apresentar o código de retirada para receber o produto. Entretanto, para que o usuário consiga sabe quando e se o pedido dele está pronto, o próprio aplicativo avisará dessa conclusão e que ele está pronto para retirar

Passando para os funcionários agora, o responsável pelo atendimento irá receber os pedidos pelo aplicativo e redireciona-los para os cozinheiros. Além disso ele também irá visualizar o código e entregar o pedido para o aluno. Já os cozinheiros, além de receber e preparar os pedidos, eles também irão marcar eles como concluído, fazendo essa notificação aparecer para o aluno.

## Alternativas Consideradas

**1. Pagamento realizado pelo aplicativo**

- Reduziria ainda mais o tempo de atendimento na retirada.
- Eliminaria a etapa de pagamento presencial.

**Motivo para não adoção:** foi descartado por exigir integração com meios de pagamento, aumentar a complexidade do sistema e tornar a solução menos simples para a primeira versão.

**2. Agendar o horário de retirada**

- Mais fácil para o aluno
- Evita filas em um horário específico

**Motivo para não adoção:** foi desconsiderada por conta de aumentar o trabalho constante dos cozinheiros, fazendo o trabalho deles mais exaustivo.

## Consequências

#### Vantagens

Como vantagem, espera-se uma redução significativa das filas, pois o aluno realiza o pedido antecipadamente e, ao chegar à cantina, apenas efetua o pagamento e retira sua refeição. Além disso, a cantina pode iniciar o preparo antes do horário de maior movimento, melhorando a organização do atendimento.

#### Desvantagens
Como desvantagem, o aluno ainda precisará passar pelo caixa para realizar o pagamento, o que significa que ainda existirá uma pequena fila nesse ponto do atendimento. Além disso, podem ocorrer pedidos que não sejam retirados, gerando desperdício de alimentos ou prejuízo operacional para a cantina caso o preparo já tenha sido iniciado.
