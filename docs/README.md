# Documentação

Esta pasta reúne toda a documentação técnica do projeto. O objetivo é manter o conhecimento sobre decisões, arquitetura, API, banco de dados e requisitos centralizado e fácil de encontrar — tanto para quem já está no projeto quanto para quem está entrando agora.

## Estrutura

| Pasta | Serve para |
|---|---|
| [`adr/`](adr/README.md) | Registrar as decisões de arquitetura tomadas e o porquê delas |
| [`diagrams/`](diagrams/README.md) | Guardar diagramas visuais do sistema (classes, sequência, arquitetura etc.) |
| [`api/`](api/README.md) | Documentar os endpoints da API e como usá-los |
| [`database/`](database/README.md) | Documentar o modelo de dados e scripts do banco |
| [`requirements/`](requirements/README.md) | Registrar requisitos funcionais, não funcionais e regras de negócio |

## Como usar

Antes de criar um novo documento, verifique se ele já não se encaixa em uma pasta existente. Cada subpasta tem seu próprio `README.md` com orientações específicas sobre nomenclatura e conteúdo esperado.
