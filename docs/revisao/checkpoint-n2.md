# Checkpoint da Aula 17 — Avaliação N2 (avaliação final da UC)

Esta versão congela a solução antes da Avaliação N2. A Avaliação N2 é individual
(Google Forms/Classroom + exercício prático de codificação) e cobre os temas das
Aulas 11 a 16 — é a avaliação final desta Unidade Curricular.

## Deve estar demonstrável
- Publicação e consumo de eventos via mensageria (evento `shipment.criado`).
- Ao menos dois consumidores independentes reagindo ao mesmo evento.
- Roteamento de eventos por routing key (ex.: separando categorias de remessa).
- Cache distribuído (Redis) aplicado ao cálculo de frete, com ganho de desempenho
  mensurável (com e sem cache).
- API Gateway configurado — ou a justificativa técnica de por que não foi necessário.
- ADRs atualizados refletindo as decisões tomadas desde o checkpoint N1.
