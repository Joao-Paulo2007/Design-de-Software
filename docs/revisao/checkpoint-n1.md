# Checkpoint da Aula 10 — Avaliação N1

Nesta versão não há grande incremento de implementação: ela representa um
**congelamento controlado** do projeto para avaliação. A Avaliação N1 é individual
(Google Forms/Classroom + exercício prático de codificação) e cobre os temas das
Aulas 01 a 09.

## Evidências para mostrar
- Evolução entre o legado (`LegacyShippingService`) e a organização atual do projeto.
- Requisitos arquiteturais levantados (funcionais e não funcionais).
- Estilo arquitetural escolhido para a NexusLog, com justificativa (matriz de trade-offs).
- Estrutura inicial de backend (Spring Boot) e frontend (Angular), comunicando-se via REST.
- Pontos ainda intencionalmente pendentes para a etapa N2 (mensageria, cache, gateway).
