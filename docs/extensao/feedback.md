# Registro de feedback e refinamento

| Feedback | Impacto | Decisão | Artefato alterado |
|---|---|---|---|
| Exemplo: usuário quer aviso apenas em mudanças relevantes | Roteamento de eventos pode filtrar por routing key | criar política de notificação seletiva | diagrama + código + ADR |

## Regra
Feedback não deve ser incorporado automaticamente. O grupo deve justificar se aceita, adapta ou rejeita, registrando a consequência.
